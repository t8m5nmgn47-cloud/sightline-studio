# BI v8 rollout

The daily intelligence refresh now produces a compact internal operator digest through Sightline's existing optional Slack notification hook.

## Notification rule

The refresh stays silent when nothing meaningful changed.

A digest is sent only when at least one of these occurs:

- a new actionable recommendation is created
- an old active recommendation expires
- a business refresh fails

## Digest content

The digest includes:

- count of new recommendations
- count of expired recommendations
- count of processing errors
- number of businesses processed
- top five new decisions
- priority ordering: Fix → Repeat → Test
- confidence label for each top decision
- up to three refresh issues
- link to the private Intelligence Portfolio

## Privacy and delivery

The digest is internal operator messaging. It uses the existing `SLACK_WEBHOOK_URL` integration through `notifySlack`. If the webhook is not configured, the notification helper remains a safe no-op and the intelligence refresh still succeeds.

No lead email address or customer PII is included in the digest.

## Schedule

The digest is generated by the existing scheduled `/api/intelligence-refresh` run, so it does not add another cron or duplicate intelligence processing.

## Validation

Regression coverage verifies:

- quiet-day silence
- new-recommendation notifications
- Fix-first priority ordering
- expiry-only notifications
- refresh-error notifications
- top-five decision limit
- portfolio link generation

No database migration is required.
