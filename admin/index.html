How to launch a new prospect site (start to finish)
1

Generate the demo — no code needed

Double-click Sightline Site Maker.command in your sightline-studio folder. Type the prospect's website, click Generate site, preview it, then Publish to live site. Done — it's at /demos/<their-name>/ two minutes later.

2

Want the full funnel instead? (advanced)

Add the business to top30.json and run ./release.sh — it regenerates the demo (8 styles), teardown, and funnel, runs the QA gate, and stops if anything fails. Then ./deploy.sh "added <business>" pushes it live at /p/<slug>/.

3

Send it

Grab their funnel link from the Pipeline (stage 3) — it has a ready-to-send email per prospect.

4

When they buy

Add them under Subscribers (stage 5), run the Onboarding checklist (stage 4), switch on their add-ons, point their domain at the site, and install the legal pages.

🔒 Lock this admin. Subscriber data lives in your Supabase database behind a magic-link sign-in.
